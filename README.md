# Speak Right – English Grammar Book

A colourful, phone-friendly English grammar book for spoken fluency, written for Tamil-medium learners.

- 37 chapters in 6 parts: Foundations, Tenses, Modals, Building Sentences, Small Words, Speaking Fluency
- Every chapter: simple rules, colour-coded examples, a Tamil explanation (தமிழில்), common mistakes, speaking practice and a quiz

Read it online: https://aravindanr-create.github.io/speak-right-grammar/
